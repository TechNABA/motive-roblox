# Motive animations in Roblox Studio

The plugin panel is in Italian: this guide shows its buttons and messages as they appear, with the English meaning in
brackets.

## 1. Install the plugin (once)

Open this link and click **Get**, then **Install**:
<https://create.roblox.com/store/asset/91142360787208/Motive-Animation-Converter>
(on the Creator Store the plugin is called **Motive Animation Converter**)

Then open Roblox Studio: the **Animazioni Motive** panel appears on the right.

### Without the store

If the link doesn't work or you can't use the Creator Store:

1. Download the plugin file: <https://github.com/TechNABA/motive-roblox/releases/latest/download/MotiveAnimazioni.rbxmx>
2. In Studio: **File > New > Baseplate**.
3. Drag `MotiveAnimazioni.rbxmx` into the Studio window: the **AnimazioniMotive** script appears in the **Explorer**.
4. Right-click the script > **Save as Local Plugin...** and confirm without changing the name or folder.
5. Delete the script from the scene (select it and press **Delete**). The **Animazioni Motive** panel stays.

Installed this way, the plugin doesn't update itself: if your teacher tells you there is a new version, repeat these
steps.

## 2. Use the animations

1. Save the `.zip` package your teacher sent you on your computer. **You don't need to extract it.**
2. In Studio: **File > New > Baseplate**.
3. **Avatar > Character** tab: create your avatar.
4. In the **Animazioni Motive** panel click **Apri pacchetto...** (Open package) and choose the `.zip` file.
5. Click an animation. Wait for the bar to finish and for the panel to say **Fatto!** (Done!)
6. **Avatar > Animation Editor** tab, then choose the animation from the menu. Press Play in the timeline.

**Several avatars at once**: select them while holding **Ctrl** (on Mac **Cmd**), then click the animation.

## If something goes wrong

Read the message in the panel: it tells you what to do. The most common cases:

- **I can't see the panel**: **Plugins > Animazioni Motive** tab.
- **"Nella scena non c'e' nessun avatar"** (there is no avatar in the scene): do step 3.
- **"Ci sono ... avatar"** (there are ... avatars): select the ones to animate, then click the animation again.
- **"c'era gia'"** (was already there): that avatar already has the animation: open it from the Animation Editor.
- **You have a folder instead of the .zip** (you extracted it, or on Mac Safari did it by itself): that's fine.
  Click **Apri pacchetto...**, go into the folder, select all the files (**Ctrl+A**, on Mac **Cmd+A**) and confirm.
- **You closed Studio**: open the package again with **Apri pacchetto...**.
